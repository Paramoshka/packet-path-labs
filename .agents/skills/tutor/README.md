# Tutor

Repository-local copy of [kevinnio/tutor](https://github.com/kevinnio/tutor/tree/v0.6), version **v0.6**, by Kevin Perez.

`SKILL.md` and `references/` are copied without changes. The original MIT license is included in `LICENSE`.

## Usage

In Codex, invoke the skill explicitly:

```text
$tutor Пройди со мной лабу 5
```

The tutor teaches in your language, gives one action at a time, explains commands, and verifies your results. You run the commands and make the changes yourself.
